# RazorNet 1.0.0

The first release of RazorNet, a program for computing and visualizing minimum-length networks that realize
a metric exactly: distances, or sequences via their Hamming distances, become a weighted graph with
auxiliary vertices whose shortest paths reproduce the input. Built on SplitsTree.

## New features

- RazorNet: minimum-length networks from distance matrices, computed with the Strict and the Relaxed
  strategy under a time budget.
- RazorHaploNet: haplotype networks from aligned sequences, with trait pie charts and a world map.
- The Shave filter: reduces a network to its well-supported part.
- Imports distances (Nexus, PHYLIP, CSV) and alignments (FASTA, Nexus, PHYLIP); exports networks as GML
  and as images; workflow files (.stree6) that SplitsTree opens as well.
- Help → Check for Updates looks at the releases of this repository.
